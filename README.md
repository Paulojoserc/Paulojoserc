## 👨‍💻 Sobre mim

Passei os últimos **18 anos** sustentando infraestrutura crítica — servidores, redes, firewall, virtualização, monitoramento — sempre resolvendo problema real, sob pressão, sem rede de segurança. Hoje estou usando essa base para migrar para **DevOps e desenvolvimento full-cycle**: já trago comigo o que muita gente que só programa não tem — entendo o que acontece embaixo do código, desde a VM até o firewall.

Estou construindo essa transição na prática, não só na teoria: laboratório próprio em Docker/Proxmox, projetos pessoais com Java + Spring Boot e React, e experimentação com IA local (Ollama/LLMs).
